ChartJS Demo
==============================

Demonstration on some functions of 'Chart.js'

This includes:
* bar-chart
* line-chart
* pie-chart
* doughnut
* radar-chart
* polar-area-chart

For line and radar-chart:
* tension / interpolation of line between two points

Data is provided by selectable Items.

Required libraries:
* Chart.js (`lib-chartjs3`: `^3.6.0`)
